# netso

**Secure decentralized platform** — self-sovereign identity (SSI) and end-to-end
encryption for trust between parties without a central authority.

## Recognition
INCIBE National Cybersecurity Competition **2020 — Top 10** (Entrepreneurs track):
a secure decentralized platform built on SSI and E2E encryption.

## Scope
- Decentralized / self-sovereign identity (DID/SSI)
- End-to-end encrypted messaging and data exchange
- Trust and resilience without a central authority

## Status
TrustSentinel home for the project. The original 2020 prototype repository was not
preserved; this repo is the clean starting point — design notes and implementation
to be added. Related work: [marshmallows](https://github.com/trustsentinel/marshmallows)
(secure mesh) and [argos](https://github.com/trustsentinel/argos) (P2P network intelligence).
